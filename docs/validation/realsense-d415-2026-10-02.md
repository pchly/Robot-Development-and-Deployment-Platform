# RealSense D415台架验证记录

- 日期：2026-10-02
- Edge节点：Jetson AGX Orin Developer Kit
- 系统：JetPack 6.2.3、L4T R36.5.2、Ubuntu 22.04、aarch64
- 相机：RealSense D415
- SDK wheel：pyrealsense2 2.58.4.10922、CPython 3.10、aarch64
- Runtime镜像：robot-platform/realsense-runtime:0.1.0-wheel

## 设备身份

- SDK序列号：`125322060182`
- ASIC、固件升级和USB/UVC传输层序列号：`123423024767`
- 固件：`5.13.0.50`
- 产品ID：`0AD3`
- USB连接：3.2，5000 Mbps

## 已通过项目

1. 容器内SDK枚举真实D415；
2. 640×480、30 FPS配置同步采集RGB8和Depth Z16；
3. 丢弃30组预热帧后的300组样本达到29.55 FPS；
4. 拔出后设备在Studio中消失，重插后自动恢复且仍为5000 Mbps；
5. 重插后相同基准达到29.35 FPS；
6. 连续运行时拔出相机，Runtime进入`degraded`和`reconnecting`；
7. 插回后同一容器进程恢复为`running`，恢复计数为1，并继续取得60组同步帧。
8. 连续运行300.81秒，共采集8900组同步帧；稳态窗口约29.76 FPS，全程无降级和重连。

## 已知修正

自动恢复Runtime首次使用了Python 3.11新增的`datetime.UTC`，在Jetson Python 3.10启动失败。
现已改为`timezone.utc`；失败发生在SDK加载与硬件访问之前。
