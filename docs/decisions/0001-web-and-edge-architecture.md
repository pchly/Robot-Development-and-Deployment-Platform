# ADR-0001：采用 Web Studio 与 Edge Agent 混合架构

- 状态：已接受
- 日期：2026-10-01

## 背景

平台既需要便于跨平台访问、团队协作和持续升级，也需要连接串口、CAN、相机、ROS 2、GPU和厂商驱动。纯网页无法可靠承担本地硬件运行，纯桌面客户端又会增加跨平台发布与协作成本。

## 决策

采用三个逻辑独立的部分：

1. React Web Studio 负责用户交互；
2. FastAPI Platform API 负责控制面和领域数据；
3. Python Edge Agent 负责本机资源和运行时接入。

第一阶段允许三者运行在同一台电脑上，后续可将 Platform API 部署到局域网或云端。

## 结果

正面影响：

- Web 界面可以独立迭代，并支持远程和多人使用；
- 硬件访问与界面解耦；
- Edge Agent 可以在浏览器关闭或网络短暂中断时继续运行；
- 后续可以按需封装为桌面安装包。

代价：

- 需要维护跨进程协议；
- 必须设计节点身份、认证、升级和断线恢复；
- 本地开发需要同时启动多个进程。
