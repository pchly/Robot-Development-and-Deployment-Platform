# ADR-0009：把相机到执行器标定作为可部署制品

- 状态：已采纳
- 日期：2026-10-07

## 背景

视觉引导机械臂流程需要相机内参和相机坐标系到机械臂基座坐标系的刚体变换。若把这些数值作为普通工作流参数保存在画布节点中，会产生三个工程问题：配置容易被误改、无法证明运行时使用的是哪次标定结果、相机或机械臂更换后仍可能误用旧标定。

## 决策

标定结果使用 `calibration_profile` 制品类型管理，文件契约为 `robot.calibration.camera-to-arm.v1`。制品必须包含：

- 唯一标定 ID 与语义化版本；
- 相机传输类型、设备 ID、坐标系和内参；
- 执行器适配器 ID、设备 ID和目标坐标系；
- 平移与 RPY 旋转；
- 固定 SHA-256 摘要和可选质量信息。

Platform API 在 Catalog 加载时校验文件结构、Manifest 对应关系和摘要。Edge Agent 将文件安装到独立版本目录，通过原子指针激活，并在库存中上报实际摘要。空间定位 Runtime 只接受部署计划锁定、节点已激活且设备绑定一致的标定制品。

标定 JSON 与操作系统无关，因此当前模拟标定只提供一个跨平台分发文件。将来若某种标定工具链或驱动产生平台相关内容，可以沿用制品变体机制，为 Windows、Linux、x86_64 或 aarch64 提供不同发行变体；运行时仍引用同一个逻辑制品 ID。

## 后果

- 工作流修订记录任务参数和制品版本，不再承担标定数据本体的版本管理。
- 相机或机械臂实例不匹配时，部署会在运动发生前失败。
- 新节点必须先安装所需标定制品，工作流才会变为可执行。
- 真实 RealSense 与真实机械臂接入时，需要生成绑定真实序列号/设备 ID 的新标定制品，不能复用模拟标定。

## 后续动作

- 增加真实相机与机械臂的标定采集、质量评估和发布工具。
- 在 Studio 中提供标定制品详情与设备绑定提示。
- 在部署前检查页面展示标定版本、摘要和设备匹配结果。
